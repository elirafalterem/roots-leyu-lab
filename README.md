# roots-leyu-lab

一个用于归档和发布独立 HTML 页面的仓库。

## 项目简介

本仓库主要用于存放、整理和发布各类独立开发的 HTML 页面。这些页面不针对特定域名或网站，而是作为独立的静态资源进行归档和展示。每个页面可能包含不同的内容或功能，均以单文件 HTML 形式保存，便于直接访问和引用。

## 目录说明

```
roots-leyu-lab/
├── pages/          # 存放各个独立的 HTML 页面文件
├── assets/         # 页面引用的静态资源（如 CSS、JS、图片等）
└── README.md       # 本文件
```

- **pages/**：每个 HTML 文件独立存放，文件名应反映页面主题或功能。
- **assets/**：如果页面需要外部资源，建议统一放置在此目录下，保持结构清晰。

## 页面归档说明

- 每个 HTML 页面均为自包含或依赖 `assets/` 目录下的资源。
- 页面内容可能包括工具、演示、实验性项目或学习笔记等，不限定具体主题。
- 归档的页面可能不定期更新、修正或移除，恕不逐一通知。
